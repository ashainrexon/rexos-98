# RexOS 98

> My personal portfolio website, inspired by the classic Windows 98 operating system.

🌐 **Live Website:** Head over to ashainrexon.com

Rather than using a traditional portfolio layout, I wanted to create an interactive desktop experience where visitors can explore my projects, experience, interests and background through different apps and windows.

The project combines my interests in **physics, astronomy, software development, gaming, anime and retro computing** into one interactive portfolio.

## 🛠️ Built With

- Next.js
- React
- TypeScript
- CSS
- Framer Motion
- Vercel

## ✨ Features

- 🖥️ Windows 98-inspired desktop interface
- 🪟 Draggable and closable application windows
- 📁 Interactive desktop applications
- 📅 Calendar-style work experience section
- 👤 Personal profile
- 💻 Projects showcase
- 📄 CV section
- 🎵 Music player
- ⚙️ Desktop settings
- 🕐 World clock
- 🚀 Retro-inspired visual design
- 📱 Responsive design
